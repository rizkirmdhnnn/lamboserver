# Roadmap: LamboServer — v1.0 Remove pgAdmin, Replace with CloudBeaver

## Overview

This milestone removes all pgAdmin code and infrastructure from the codebase, leaving CloudBeaver as the sole PostgreSQL admin interface. Phase 1 deletes the pgAdmin package and strips every reference from Go backend files. Phase 2 verifies CloudBeaver is fully functional as the replacement and cleans up any remaining references in docs and the codebase.

## Phase Details

### Phase 1: Remove pgAdmin
**Goal**: All pgAdmin code is deleted and the Go backend compiles cleanly without it
**Depends on**: Nothing (first phase)
**Requirements**: REM-01, REM-02, REM-03, REM-04, REM-05, REM-06
**Success Criteria** (what must be TRUE):
  1. `internal/services/pgadmin/` directory and all its files no longer exist in the repository
  2. `app.go` has no pgAdmin imports, fields, initialization calls, or `OpenPgAdmin()` method
  3. pgAdmin WebAdmin registration is absent from the service registry
  4. `internal/system/paths.go` and its test file contain no pgAdmin path helpers
  5. `frontend/wailsjs/` contains no auto-generated bindings referencing pgAdmin
**Plans:** 2 plans

Plans:
- [x] 01-01-PLAN.md — Delete pgAdmin package and strip all Go backend references
- [x] 01-02-PLAN.md — Regenerate Wails bindings and run full verification

### Phase 2: Verify CloudBeaver and Clean Up
**Goal**: CloudBeaver serves as the working sole PostgreSQL admin interface and no pgAdmin references remain anywhere in the codebase or docs
**Depends on**: Phase 1
**Requirements**: CB-01, CB-02, DOC-01, DOC-02
**Success Criteria** (what must be TRUE):
  1. Opening the PostgreSQL database page shows the CloudBeaver panel — no pgAdmin panel or link exists
  2. CloudBeaver connection presets point to the local PostgreSQL instance (correct host/port/socket)
  3. `docs/DEVELOPMENT.md` contains no mention of pgAdmin
  4. A codebase-wide search for "pgadmin" (case-insensitive) returns zero results
