# Milestone v1.0: System Tray Integration

**Status:** SHIPPED 2026-04-18
**Phases:** 1-4
**Total Plans:** 7

## Overview

This milestone added macOS system tray integration to LamboServer. The work proceeded in four phases: first the high-risk CGO foundation and window lifecycle, then service controls, then quick-access links, and finally the build pipeline changes needed to ship the feature.

## Phases

### Phase 1: Tray Foundation & Window Lifecycle
**Goal**: A functional tray icon exists in the macOS menu bar and the window hides/restores correctly from it
**Depends on**: Nothing (first phase)
**Requirements**: TRAY-01, TRAY-02, TRAY-03, WNDW-01, WNDW-02, WNDW-03, WNDW-04
**Plans**: 2 plans
- [x] 01-01-PLAN.md — Create custom CGO tray package with NSStatusBar icon, ObjC bridge, and template icon assets
- [x] 01-02-PLAN.md — Wire tray into App lifecycle (HideWindowOnClose, startup/shutdown integration) and verify

### Phase 2: Service Controls
**Goal**: Users can see the status of each service and trigger Start/Stop/Restart directly from the tray menu
**Depends on**: Phase 1
**Requirements**: SRVC-01, SRVC-02, SRVC-03
**Plans**: 2 plans
- [x] 02-01-PLAN.md — Expand AppController interface with service methods and add CGO bridge callbacks
- [x] 02-02-PLAN.md — Implement ObjC service menu items with colored status dots, submenus, NSMenuDelegate refresh

### Phase 3: Quick Access Links
**Goal**: Users can open configured sites and web admin tools in the browser directly from the tray menu
**Depends on**: Phase 2
**Requirements**: QKAC-01, QKAC-02, QKAC-03
**Plans**: 2 plans
- [x] 03-01-PLAN.md — Expand AppController interface, add CGO callbacks, C header declarations, and App methods
- [x] 03-02-PLAN.md — Implement ObjC Quick Access submenu with site items, web admin items, refresh logic

### Phase 4: Build Pipeline
**Goal**: The app builds and ships correctly with CGO tray support
**Depends on**: Phase 3
**Requirements**: TRAY-04, TRAY-05
**Plans**: 1 plan
- [x] 04-01-PLAN.md — Add CGO_ENABLED=1 and binary verification to CI pipeline and local build script

## Milestone Summary

**Key Decisions:**
- Custom CGO package using NSStatusBar directly — all standard systray libraries incompatible with Wails v2
- Hide-to-tray on window close, no confirmation dialog
- Fire-and-forget service actions, status refresh on menu reopen
- No LSUIElement — Dock icon stays visible, dynamic hiding deferred to v2
- No Info.plist patching needed — NSStatusBar works at runtime via CGO

**Issues Resolved:**
- ObjC linker conflicts with Wails v2 (solved by custom CGO package)
- Wails WindowShow freeze bug #2572 (used runtime.Show instead)
- CGO universal binary compilation for CI

**Technical Debt:**
- Icon2x exported but unused in icon.go (macOS handles retina via template scaling)
- No explicit AppController compile-time assertion in app.go
