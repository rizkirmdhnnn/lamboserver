<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Tray callbacks -> Wails runtime | ObjC menu actions invoke wailsRuntime.Show/Quit via CGO; nil context could crash |
| HideWindowOnClose -> App state | Window close no longer triggers beforeClose; app stays alive silently |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Denial of Service | shutdown() race | mitigate | Nil-guard `a.Tray` in shutdown(): `if a.Tray != nil { a.Tray.Destroy() }`. Prevents panic if shutdown called before startup completes. |
| T-02-02 | Information Disclosure | Services running after window close | accept | By design (WNDW-04, D-13): services are independent launchd daemons. Users expect this -- it is the core feature. Dock icon remains visible as visual indicator. |
| T-02-03 | Denial of Service | Double shutdown via Tray Quit + Wails OnShutdown | mitigate | Tray "Quit" only calls `runtime.Quit(ctx)` which triggers Wails OnShutdown -> app.shutdown(). Service stop methods are idempotent (stopping already-stopped service is a no-op). Per Pitfall 4 prevention. |
</threat_model>
