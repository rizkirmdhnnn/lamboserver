Update `.github/workflows/release.yml` with two changes:

1. **Add CGO_ENABLED=1 to the build step** (per D-04). Change the "Build universal .app" step from:
```yaml
      - name: Build universal .app
        run: wails build -platform darwin/universal -clean
```
to:
```yaml
      - name: Build universal .app
        run: wails build -platform darwin/universal -clean
        env:
          CGO_ENABLED: "1"
```

2. **Add a verification step immediately after the build step and before the codesign step** (per D-05). Insert this new step:
```yaml
      - name: Verify CGO tray linkage
        run: |
          BINARY="build/bin/LamboServer.app/Contents/MacOS/LamboServer"
          echo "Checking Cocoa.framework linkage..."
          otool -L "$BINARY" | grep -q "Cocoa.framework" || { echo "FAIL: Cocoa.framework not linked"; exit 1; }
          echo "OK: Cocoa.framework linked"
          echo "Checking universal binary..."
          lipo -info "$BINARY" | grep -q "x86_64" || { echo "FAIL: missing x86_64 arch"; exit 1; }
          lipo -info "$BINARY" | grep -q "arm64" || { echo "FAIL: missing arm64 arch"; exit 1; }
          echo "OK: Universal binary (arm64 + x86_64)"
```

Do NOT change any other steps. The step order after changes should be:
1. checkout
2. Setup Go
3. Setup Node.js
4. Install Wails
5. Install frontend dependencies
6. Get version from tag
7. Build universal .app (with CGO_ENABLED env)
8. **Verify CGO tray linkage** (NEW)
9. Ad-hoc codesign
10. Create DMG
11. Create GitHub Release
