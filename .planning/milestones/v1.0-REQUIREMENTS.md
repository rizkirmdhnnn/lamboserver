# Requirements Archive: v1.0 System Tray

**Archived:** 2026-04-18
**Status:** All requirements satisfied

## v1 Requirements (All Complete)

### Tray Foundation
- [x] **TRAY-01**: System tray icon is visible in macOS menu bar when app is running — Validated
- [x] **TRAY-02**: Tray icon uses monochrome template image that adapts to macOS dark/light mode — Validated
- [x] **TRAY-03**: Custom CGO package (`internal/tray/`) using NSStatusBar directly, no third-party systray libraries — Validated
- [x] **TRAY-04**: Post-build script patches Info.plist for correct tray behavior — Satisfied via D-03: no patching needed, existing plist verified correct
- [x] **TRAY-05**: CI pipeline updated to support CGO builds with system tray — Validated

### Window Lifecycle
- [x] **WNDW-01**: Closing the main window hides to tray instead of quitting (no confirmation dialog) — Validated
- [x] **WNDW-02**: "Show Window" menu item in tray reopens the main application window — Validated
- [x] **WNDW-03**: "Quit" menu item stops all running services and exits the application — Validated
- [x] **WNDW-04**: Services keep running while app is minimized to tray — Validated

### Service Controls
- [x] **SRVC-01**: Tray menu shows per-service status indicators (running/stopped) for Nginx, MySQL, PHP, PostgreSQL, dnsmasq — Validated
- [x] **SRVC-02**: Each service has a submenu with Start, Stop, and Restart actions — Validated
- [x] **SRVC-03**: Tray menu refreshes service status after each action completes — Validated (refresh on menu reopen per D-06 design)

### Quick Access
- [x] **QKAC-01**: Tray menu lists configured sites with "Open in Browser" action (capped at 15 entries) — Validated
- [x] **QKAC-02**: Tray menu has "Open phpMyAdmin" item (shown only when phpMyAdmin is installed) — Validated
- [x] **QKAC-03**: Tray menu has "Open pgweb" item (shown only when pgweb is installed) — Validated
