## v1.0 Requirements

Requirements for milestone v1.0: Remove pgAdmin, Replace with CloudBeaver.

### Removal

- [x] **REM-01**: pgAdmin Go package (`internal/services/pgadmin/`) is fully deleted
- [x] **REM-02**: pgAdmin manager, import, field, and initialization removed from `app.go`
- [x] **REM-03**: pgAdmin WebAdmin registration removed from service registry
- [x] **REM-04**: pgAdmin path helpers removed from `internal/system/paths.go` and tests
- [x] **REM-05**: `OpenPgAdmin()` method removed from App struct
- [x] **REM-06**: Wails auto-generated bindings for pgAdmin removed from `frontend/wailsjs/`

### CloudBeaver

- [x] **CB-01**: CloudBeaver serves as sole PostgreSQL admin interface
- [x] **CB-02**: CloudBeaver connection presets correctly target local PostgreSQL instance

### Documentation

- [x] **DOC-01**: `docs/DEVELOPMENT.md` updated to remove pgAdmin references
- [x] **DOC-02**: Any remaining pgAdmin references in codebase are cleaned up
