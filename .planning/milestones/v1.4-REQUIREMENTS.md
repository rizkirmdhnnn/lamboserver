# Requirements: LamboServer

**Defined:** 2026-04-17
**Core Value:** Developers can start, stop, and manage their entire local development stack from a single desktop app without touching the terminal.

## v1.4 Requirements

Requirements for macOS Installer milestone. Each maps to roadmap phases.

### App Bundle

- [ ] **BUNDLE-01**: App has proper `wails.json` info block with productName, productVersion, and copyright
- [ ] **BUNDLE-02**: App uses correct `CFBundleIdentifier` (reverse-DNS, not default `com.wails.LamboServer`)
- [ ] **BUNDLE-03**: `Info.plist` renders correct metadata from `wails.json` info block

### App Icon

- [ ] **ICON-01**: App has a custom LamboServer icon replacing the Wails placeholder
- [ ] **ICON-02**: Icon is generated as `.icns` with all required macOS sizes (16x16 through 1024x1024)

### Production Build

- [ ] **BUILD-01**: `wails build` produces a universal binary (.app) for both Intel and Apple Silicon
- [ ] **BUILD-02**: Homebrew binaries (nginx, php, mysql, etc.) are found when app is launched from Finder (PATH fix)
- [ ] **BUILD-03**: All service management functions work correctly when running as bundled .app from /Applications

### Code Signing

- [ ] **SIGN-01**: `.app` bundle is ad-hoc signed with `codesign -s -`
- [ ] **SIGN-02**: `entitlements.plist` exists with network entitlements (no sandbox, no Hardened Runtime)
- [ ] **SIGN-03**: Signed app passes `codesign --verify --deep`

### DMG Packaging

- [ ] **DMG-01**: DMG installer is created with drag-to-Applications layout
- [ ] **DMG-02**: Build script automates the full pipeline (build, sign, package DMG)

### Documentation

- [ ] **DOC-01**: Release notes include Gatekeeper workaround instructions (Sequoia: System Settings > Privacy & Security > Open Anyway)

## Out of Scope

| Feature | Reason |
|---------|--------|
| Notarization | Requires Apple Developer account ($99/year) — not available |
| Hardened Runtime | Blocks exec.Command calls to Homebrew services; incompatible with app architecture |
| App Sandbox | Kills all service management functionality (Nginx, PHP, MySQL, etc.) |
| Mac App Store distribution | Requires Developer account + sandboxing + notarization |
| .pkg installer | DMG is the standard for drag-to-Applications desktop apps |
| Auto-update | Future milestone — focus on initial distribution first |
