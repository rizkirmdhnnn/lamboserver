**Step B: Create scripts/generate-icns.sh**

Create the directory `scripts/` if it does not exist. Write `scripts/generate-icns.sh` with the following exact content:

```bash
#!/bin/bash
set -e

SRC="build/appicon.png"
ICONSET="build/darwin/LamboServer.iconset"
ICNS_OUT="build/darwin/iconfile.icns"

mkdir -p "$ICONSET"

sips -z 16   16   "$SRC" --out "$ICONSET/icon_16x16.png"
sips -z 32   32   "$SRC" --out "$ICONSET/icon_16x16@2x.png"
sips -z 32   32   "$SRC" --out "$ICONSET/icon_32x32.png"
sips -z 64   64   "$SRC" --out "$ICONSET/icon_32x32@2x.png"
sips -z 128  128  "$SRC" --out "$ICONSET/icon_128x128.png"
sips -z 256  256  "$SRC" --out "$ICONSET/icon_128x128@2x.png"
sips -z 256  256  "$SRC" --out "$ICONSET/icon_256x256.png"
sips -z 512  512  "$SRC" --out "$ICONSET/icon_256x256@2x.png"
sips -z 512  512  "$SRC" --out "$ICONSET/icon_512x512.png"
sips -z 1024 1024 "$SRC" --out "$ICONSET/icon_512x512@2x.png"

iconutil -c icns "$ICONSET" -o "$ICNS_OUT"

echo "Generated: $ICNS_OUT"
```

Make the script executable: `chmod +x scripts/generate-icns.sh`

Per D-06: Icon must be generated using sips + iconutil (not Wails auto-generation).
