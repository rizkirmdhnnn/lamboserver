  <action>
Run the full build pipeline:
```bash
bash scripts/build-dmg.sh
```

This will take several minutes (wails build compiles Go + frontend for two architectures).

After the script completes successfully, verify all three pipeline outputs:

**Verify 1 -- Signature is ad-hoc with entitlements (SIGN-01, SIGN-02, SIGN-03):**
```bash
codesign -dv build/bin/LamboServer.app 2>&1 | grep "Signature=adhoc"
codesign --verify --deep --strict build/bin/LamboServer.app
codesign -d --entitlements - build/bin/LamboServer.app 2>&1 | grep "allow-jit"
```
All three must succeed. The third command confirms entitlements are embedded (not empty like the pre-Phase-9 state).

**Verify 2 -- DMG exists and has correct contents (DMG-01):**
```bash
test -f LamboServer-1.0.0.dmg && echo "DMG exists"
hdiutil attach LamboServer-1.0.0.dmg -nobrowse
ls /Volumes/LamboServer/
# Must show: LamboServer.app and Applications (symlink)
hdiutil detach /Volumes/LamboServer
```

**Verify 3 -- DMG is read-only UDZO format:**
```bash
hdiutil imageinfo LamboServer-1.0.0.dmg | grep "Format Description"
# Should show: UDIF read-only compressed (zlib)
```

If any verification fails, diagnose and fix the issue in build-dmg.sh, then re-run.
