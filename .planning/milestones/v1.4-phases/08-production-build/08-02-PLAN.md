
This command will:
- Install npm dependencies via `frontend:install` hook
- Build React frontend via `frontend:build` hook

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| wails build -> .app bundle | Build toolchain produces the artifact; compromised toolchain = compromised app |
| .app -> exec.Command(service binaries) | App executes binaries from ~/.lamboserver/ — relies on file system permissions |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-03 | Tampering | wails build output | accept | Build runs locally on developer machine; no CI pipeline to compromise. Ad-hoc signing (Phase 9) provides no tamper resistance. Acceptable for current distribution model. |
| T-08-04 | Elevation of Privilege | exec.Command to ~/.lamboserver/ binaries | accept | BinaryLocator uses absolute paths. Binaries in ~/.lamboserver/ are user-owned. No PATH injection vector since exec.LookPath is not used when LocalPath exists. Risk is inherent to the unsandboxed architecture. |
</threat_model>
