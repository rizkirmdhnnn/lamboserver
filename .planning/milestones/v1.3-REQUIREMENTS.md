# Requirements: LamboServer

**Defined:** 2026-04-16
**Core Value:** Developers can start, stop, and manage their entire local development stack from a single desktop app without touching the terminal.

## v1.3 Requirements

Requirements for milestone v1.3: Replace CloudBeaver with pgweb.

### Cleanup

- [ ] **CLEAN-01**: CloudBeaver is fully removed from the codebase (Go code, frontend UI, config, service registration)

### pgweb

- [ ] **PGW-01**: pgweb binary is downloaded and installed into ~/.lamboserver/pgweb/
- [ ] **PGW-02**: User can start/stop pgweb from the PostgreSQL database page
- [ ] **PGW-03**: User can open pgweb in the default browser with pre-configured connection to the local PostgreSQL server
