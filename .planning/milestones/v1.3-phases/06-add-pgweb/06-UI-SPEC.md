## Component Inventory

Components this phase adds or modifies in `PgDatabasePage.tsx`:

### Web Admin Card — Not Installed State
- Renders when: `pgwebInstalled === false` AND `running === true` (PostgreSQL is running)
- Does NOT render when PostgreSQL is stopped or not installed (D-03)
- Structure: `.card` with a single `.service-row` inside
- Left side: compact text "Web Admin (pgweb)" at `.service-name` + "Not installed" at `.service-detail`
- No icon, no description paragraph (D-04)
- Right side: [Install pgweb] button — `.btn btn-primary btn-sm`
- During install: button label cycles through install step labels (matches PostgreSQL pattern)

### Web Admin Card — Stopped State
- Renders when: `pgwebInstalled === true` AND `pgwebRunning === false` AND `running === true`
- Structure: `.card` with a single `.service-row` inside
- Left side: `<span className="status-dot stopped" />` + service-name "Web Admin (pgweb)" + service-detail "Stopped"
- Right side: [Start] button — `.btn btn-primary btn-sm`

### Web Admin Card — Running State
- Renders when: `pgwebInstalled === true` AND `pgwebRunning === true`
- Structure: `.card` with a single `.service-row` inside
- Left side: `<span className="status-dot running" />` + service-name "Web Admin (pgweb)" + service-detail showing port — "Running · Port 8081"
- Right side: two buttons in `.service-actions` div — [Stop] `.btn btn-danger btn-sm` + [Open] `.btn btn-secondary btn-sm`

### Card Position in Page
Order within `PgDatabasePage.tsx` when PostgreSQL is running:
1. PostgreSQL service card (existing)
2. Web Admin (pgweb) card — NEW, inserted here
3. Create Database card (existing)
4. Databases list card (existing)

Source: D-01, D-02, D-06 from `06-CONTEXT.md`.

## Interaction States

| Action | Loading Label | Disabled During |
|--------|--------------|-----------------|
| Install pgweb | "Downloading..." → "✓ Installed" | `pgwebLoading === true` |
| Start pgweb | "Starting..." | `pgwebLoading === true` |
| Stop pgweb | "Stopping..." | `pgwebLoading === true` |
| Open pgweb | (no loading label — fire and forget) | never disabled |

The pgweb card uses its own loading state (`pgwebLoading`) independent of the PostgreSQL `loading` state. The two cards must not share loading state.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Card title (service-name) | Web Admin (pgweb) |
| Not-installed service-detail | Not installed |
| Stopped service-detail | Stopped |
| Running service-detail | Running · Port 8081 |
| Primary CTA — install | Install pgweb |
| Primary CTA — start | Start |
| Secondary CTA — open | Open |
| Destructive CTA — stop | Stop |
| Install step 1 | Downloading... |
| Install step 2 | Checking... |
| Install step complete | ✓ Installed |
| Error state — install failure | Toast with summary (first line of error, max 120 chars) + detail (full error text). Uses existing `Toast` component. |
| Error state — start/stop failure | Inline error card with left border `var(--danger)` — matches existing PostgreSQL error pattern |

No empty state needed: the Web Admin card is hidden entirely when PostgreSQL is not running (D-03), so there is no empty state to display. Absence of card IS the empty state.

No destructive confirmation dialog: Stop is a non-destructive reversible action. No modal required.

Source: D-04, D-05, D-06, D-11 from `06-CONTEXT.md`. Error pattern from `PgDatabasePage.tsx` lines 184-188.
