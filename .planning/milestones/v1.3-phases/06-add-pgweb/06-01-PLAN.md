3. `NewManager(paths *system.Paths, fs FileSystem, cmd CommandRunner) *Manager`

4. `binaryPath() string` — returns `filepath.Join(m.paths.PgwebDir(), "pgweb")`

5. `IsInstalled() bool` — calls `m.fs.Stat(m.binaryPath())`, returns true if no error

6. `Install() error`:
   - Detect arch: `arch := "arm64"` then check `if system.GetArchitecture() == "amd64" { arch = "amd64" }`
   - Build URL: `fmt.Sprintf(downloadURLTemplate, pgwebVersion, arch)`
   - `dir := m.paths.PgwebDir()`, `zipPath := filepath.Join(dir, "pgweb.zip")`
   - `m.fs.MkdirAll(dir, 0755)` — error wrap: "failed to create pgweb dir: %w"
   - `m.cmd.Run("sh", "-c", fmt.Sprintf("curl -sL '%s' -o '%s'", url, zipPath))` — error wrap: "failed to download pgweb: %w"
   - `m.cmd.Run("sh", "-c", fmt.Sprintf("unzip -o '%s' -d '%s'", zipPath, dir))` — error wrap: "failed to extract pgweb: %w"
   - `m.cmd.Run("chmod", "+x", m.binaryPath())` — error wrap: "failed to make pgweb executable: %w"
   - `m.cmd.Run("rm", "-f", zipPath)` — best-effort cleanup, ignore error
   - Post-install verification: `m.fs.Stat(m.binaryPath())` — error wrap: "pgweb binary not found at %s after extraction"
   - Import `"github.com/rizkirmdhnnn/lamboserver/internal/system"` for `system.GetArchitecture()`

7. `checkPort() error`:
   - `ln, err := net.Listen("tcp", "127.0.0.1:8081")`
   - If err: return `fmt.Errorf("port 8081 is already in use by another process")`
   - Else: `ln.Close()` and return nil

8. `Start() error`:
   - Lock mutex, defer unlock
   - If `m.IsRunning()` return nil (idempotent)
   - Call `m.checkPort()`, return error if fails
   - CRITICAL: Use `exec.Command` directly (NOT `m.cmd.Run`):
     ```go
     cmd := exec.Command(m.binaryPath(),
         "--host=127.0.0.1",
         "--user=postgres",
         "--bind=127.0.0.1",
         "--listen=8081",
         "--skip-open",
     )
     ```
   - Call `cmd.Start()` (NOT `cmd.Run()` — `Run()` blocks forever for daemons)
   - If err: return `fmt.Errorf("failed to start pgweb: %w", err)`
   - Set `m.proc = cmd`
   - Return nil

9. `Stop() error`:
   - Lock mutex, defer unlock
   - If `m.proc == nil` return nil (idempotent)
   - `m.proc.Process.Kill()` — ignore error
   - `m.proc.Wait()` — REQUIRED to reap zombie, ignore error
   - Set `m.proc = nil`
   - Return nil

10. `IsRunning() bool`:
    - If `m.proc == nil || m.proc.Process == nil` return false
    - Probe: `err := m.proc.Process.Signal(syscall.Signal(0))`
    - Return `err == nil`

11. `URL() string` — return `"http://127.0.0.1:8081"`
12. `Version() string` — return `pgwebVersion`
13. `Status() ServiceStatus` — return `ServiceStatus{Installed: m.IsInstalled(), Running: m.IsRunning(), Port: defaultPort}`

14. Add compile-time check: `var _ DaemonWebAdminService = (*Manager)(nil)`

// PgwebStatus is the frontend-facing status snapshot for pgweb.
type PgwebStatus struct {

| Boundary | Description |
|----------|-------------|
| App -> pgweb process | App launches external binary that binds an HTTP port |
| pgweb -> PostgreSQL | pgweb connects to local PG with trust auth (no password) |
| Network -> pgweb HTTP | pgweb serves HTTP on a TCP port |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-06-03 | Tampering | pgweb binary download | accept | Download over HTTPS from GitHub; local-dev-only tool, low-value target |
| T-06-04 | Information Disclosure | PostgreSQL trust auth | accept | localhost-only binding; trust auth is standard for local dev (same as existing PG config) |
