## Phase Details

### Phase 5: Remove CloudBeaver
**Goal**: CloudBeaver is fully removed from the codebase — no Go code, no frontend UI, no config, no service registration
**Depends on**: Nothing (independent cleanup)
**Requirements**: CLEAN-01
**Success Criteria** (what must be TRUE):
  1. The Go codebase contains no CloudBeaver service, installer, or type definitions
  2. CloudBeaver is not registered in the service registry or app initialization
  3. The PostgreSQL database page shows no CloudBeaver panel, button, or reference
  4. A codebase-wide search for "cloudbeaver" (case-insensitive) returns zero results
**Plans**: 1 plan
Plans:
- [x] 05-01-PLAN.md — Remove CloudBeaver from Go backend, frontend, and docs
**UI hint**: yes

### Phase 6: Add pgweb
**Goal**: Users can install, start, stop, and open pgweb from the PostgreSQL database page
**Depends on**: Phase 5
**Requirements**: PGW-01, PGW-02, PGW-03
**Success Criteria** (what must be TRUE):
  1. pgweb binary is downloaded and present at ~/.lamboserver/pgweb/ after installation
  2. User can start and stop pgweb from the PostgreSQL database page without touching the terminal
  3. User can click "Open pgweb" and it opens in their default browser connected to the local PostgreSQL server
  4. pgweb start/stop controls reflect the current running state of the service
**Plans**: 2 plans
Plans:
- [x] 06-01-PLAN.md — Create pgweb backend package and wire into app.go
- [x] 06-02-PLAN.md — Add pgweb Web Admin card to PostgreSQL page frontend
**UI hint**: yes
