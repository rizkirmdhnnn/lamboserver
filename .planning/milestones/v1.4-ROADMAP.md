## Phase Details

### Phase 7: App Bundle & Icon
**Goal**: LamboServer has correct metadata and a custom icon, ready for production bundling
**Depends on**: Nothing (first phase of milestone)
**Requirements**: BUNDLE-01, BUNDLE-02, BUNDLE-03, ICON-01, ICON-02
**Success Criteria** (what must be TRUE):
  1. Finder displays "LamboServer" (not "LamboServer" with Wails placeholder icon) when .app is opened
  2. `Info.plist` inside the .app bundle shows the correct productName, productVersion, copyright, and CFBundleIdentifier (reverse-DNS, not `com.wails.LamboServer`)
  3. Custom LamboServer icon appears in Dock, Finder, and app switcher at all required macOS sizes
**Plans:** 2 plans
Plans:
- [x] 07-01-PLAN.md — Add wails.json info block and fix CFBundleIdentifier in plist templates
- [x] 07-02-PLAN.md — Design custom LamboServer icon and generate .icns file
**UI hint**: yes

### Phase 8: Production Build
**Goal**: `wails build` produces a universal binary .app that works correctly when launched from /Applications
**Depends on**: Phase 7
**Requirements**: BUILD-01, BUILD-02, BUILD-03
**Success Criteria** (what must be TRUE):
  1. `wails build` completes without error and outputs a universal binary .app (runs on both Apple Silicon and Intel)
  2. Launching the .app from Finder (not terminal) finds Homebrew binaries — Nginx, PHP, MySQL, PostgreSQL, and other services start and stop without "command not found" errors
  3. All service management operations (install, start, stop, restart) work correctly when running from /Applications
**Plans:** 2 plans
Plans:
- [x] 08-01-PLAN.md — Create entitlements.plist and update LSMinimumSystemVersion in plist templates
- [x] 08-02-PLAN.md — Build universal binary .app and verify output with manual launch test

### Phase 9: Code Signing & DMG
**Goal**: LamboServer is distributed as a signed DMG that users can install by dragging to Applications
**Depends on**: Phase 8
**Requirements**: SIGN-01, SIGN-02, SIGN-03, DMG-01, DMG-02, DOC-01
**Success Criteria** (what must be TRUE):
  1. `codesign --verify --deep LamboServer.app` passes with no errors after ad-hoc signing
  2. A DMG file opens to show the LamboServer.app alongside an Applications folder shortcut — dragging installs the app
  3. A single build script runs the full pipeline (build, sign, create DMG) without manual steps
  4. Release notes include clear Gatekeeper workaround instructions for macOS Sequoia (System Settings > Privacy & Security > Open Anyway)
**Plans:** 2/2 plans complete
Plans:
- [x] 09-01-PLAN.md — Create build-dmg.sh script and update .gitignore
- [x] 09-02-PLAN.md — Run pipeline, verify DMG output, create release notes
